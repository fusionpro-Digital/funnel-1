# FusionPro

Marketing site for FusionPro Digital, built with Next.js from the Figma prototype.

```bash
npm install
npm run dev      # http://localhost:3005
npm run build    # production build
npm start        # serve the production build
npm run lint     # eslint
```

## Environment variables

The contact form at `/contact` emails each lead through [Resend](https://resend.com). Copy `.env.example` to `.env.local` for local work, and set the same variables in the hosting provider (Vercel: Project → Settings → Environment Variables) before deploying.

| Variable | Required | Purpose |
|---|---|---|
| `RESEND_API_KEY` | yes | API key from the Resend dashboard. While it is unset the form shows an error instead of sending. |
| `CONTACT_RECIPIENT_EMAILS` | no | Comma-separated inboxes that receive leads. Defaults are in `src/app/api/contact/route.ts`. |
| `RESEND_FROM_EMAIL` | no | The From address, on a domain verified in Resend. If Resend rejects the domain the route retries from `onboarding@resend.dev`. |

## Stack

Next.js 16 (App Router, Turbopack) · TypeScript · Tailwind CSS v4 · shadcn/ui on Radix · Geist + Playfair Display via `next/font` · Resend for the contact form.

## Assets

| Folder | Shown in | Field in `site.ts` | Format |
|---|---|---|---|
| `public/slider-image/` | Gallery grid under the hero | `galleryItems[].src` | 4:3 JPEG, ~1200px wide |
| `public/brand-logo/platforms/` | Tools & Platforms carousel | `platformLogos[].src` | SVG or PNG, dark marks on transparent; rendered 46px tall on a white tile |
| `public/service-cards/` | Service cards | `services.items[].src` | 16:10 JPEG, ~1600px wide |
| `public/testimonials/` | Testimonial slider avatars | `testimonials[].avatar` | Square SVG |
| `public/Logomark.png` | Header, footer, favicon, share image | — | PNG |

To swap an image, drop the file in the matching folder and change the `src` in `src/content/site.ts`. An image whose `src` is `null` renders a tinted placeholder; a logo without a file renders its name as text; a testimonial without an avatar shows initials.

## Things worth knowing before you change something

**The site is dark-only.** The Figma has no light variant, so tokens are declared on bare `:root` with no `.dark` class and no `prefers-color-scheme` block. Adding a light theme means adding those blocks, not editing these values.

**Headings are two-part.** `DisplayHeading` takes a `lead` (bold grotesque) and an `accent` (italic serif in the violet gradient) and stacks them. The accent is deliberately *smaller* than the lead (59px vs 63px at `lg`), which is what keeps lines like "The pieces around it aren't working together." on one line.

**Scroll reveal is CSS, not state.** `<Reveal>` renders `data-reveal="pending"`; an IntersectionObserver flips it to `"visible"`. The hidden style lives in `globals.css`, so the server HTML is complete and visible. A `<noscript>` block in the root layout un-hides everything when JS is off, and `prefers-reduced-motion` disables the effect entirely.

**The logo carousel renders its list twice.** `one-team.tsx` splits `platformLogos` into two rows and renders each row's list twice so the `-50%` keyframe lands on an identical frame. Spacing is padding on each item, not flex `gap`, for the same reason. Under `prefers-reduced-motion` the copy is hidden and the row becomes a static wrapped grid.

**The testimonial slider auto-advances.** Every 7s while it is on screen; it pauses on hover or focus, stops for good once the visitor uses the controls, and never starts under `prefers-reduced-motion`. All slides are rendered into one grid cell so the frame height never jumps.

**CTAs all point at one constant.** `CTA_HREF` in `src/content/site.ts` is `/contact`.

**Mobile is an interpretation.** The prototype only had desktop frames.

## Before launch

- **Testimonials.** The names, roles, and quotes in `testimonials` came from the design template, not from clients. Replace them with real, permitted quotes before publishing.
- **Legal pages.** `/privacy` and `/terms` carry generic copy. The Governing Law clause names no jurisdiction, and both documents should be reviewed by counsel.
- **Resend.** Set `RESEND_API_KEY` in the hosting environment and verify the sending domain in Resend so leads come from `@fusionprodigital.com`.
